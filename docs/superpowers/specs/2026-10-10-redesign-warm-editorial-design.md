# Редизайн «Тёплая редакция»

Дата: 2026-10-10 · Ветка: `redesign/warm-editorial`

## Цель

Сайт «Сенсорного книжного клуба» должен выглядеть смелее и запоминаться, а не быть очередным «уютным» шаблоном. Берём приёмы [Club Athletic](https://clubathletic.co/): строгая журнальная типографика, сетка из тонких рамок, фото на весь экран, драматургия скролла. Тёплая «книжная» интонация нынешнего бренда остаётся. В работе используем установленные скиллы: GSAP, Lenis, React Bits.

Макет выбранного варианта: `/home/claude/google_drive/sensory-redesign/b-warm-editorial.html`. Рядом лежат ещё два варианта, A и C, которые сравнивали.

### Что согласовано

- Объём: дизайн-система на всём сайте. Главная пересобирается полностью, каталог и страница набора — заметно. Тест, результаты, корзина, оформление, вход, регистрация, «спасибо» и 404 получают новый стиль через общие компоненты, их макет не перестраивается.
- Направление B «Тёплая редакция».
- На главной лента настоящих отзывов из базы.
- Анимации: GSAP + ScrollTrigger + Lenis для скролла, Framer Motion остаётся для анимаций интерфейса.

### Чего не меняем

- Функциональность и данные: тест и подбор (`matchSets`), каталог, корзина, оформление, аккаунты, отзывы, подсказки адреса, маска телефона.
- Маршруты, существующие API и схема БД. Добавляется только один эндпоинт, читающий данные.
- Тексты, кроме заголовков, где появляется акцентное курсивное слово.

### Критерии готовности

1. Все страницы в новом стиле в светлой и тёмной темах на ширине 1440, 768 и 390 px. Нет горизонтального скролла и обрезанного текста.
2. Главная содержит все секции из раздела «Главная» с работающими эффектами.
3. При `prefers-reduced-motion: reduce` нет движения, а весь контент виден сразу.
4. Пары «текст/фон» из токенов проходят WCAG AA (≥ 4,5:1).
5. `npm run typecheck` и `npm run build` проходят. Основные сценарии работают как раньше.
6. README обновлён.

## Дизайн-система

### Цвета

Архитектура не меняется: RGB-каналы в CSS-переменных в `app/globals.css` (`:root` и `.dark`), Tailwind читает их через `token()` в `tailwind.config.ts`. Имена токенов прежние, меняются значения. Добавляется пара `band`/`on-band` для полосы-призыва.

| Токен | Роль | Светлая | Тёмная |
|---|---|---|---|
| `cream` | фон страницы | `#F1EADC` | `#15110D` |
| `linen` | поверхность (карточки, поля) | `#FAF6EE` | `#1E1914` |
| `sand` | вторая поверхность, hover | `#E9E0CF` | `#29221B` |
| `ink` | основной текст | `#1B1510` | `#F0E6D6` |
| `ink-soft` | второстепенный текст | `#3D3329` | `#D6C9B5` |
| `ink-muted` | подписи | `#6E604F` | `#A3927D` |
| `terracotta` | акцент, фон кнопок | `#C4471F` | `#E8683F` |
| `terracotta-dark` | акцент в тексте и ссылках, hover | `#A93A17` | `#F08A66` |
| `terracotta-light` | тинт: выделение, фон ошибки | `#F2D6C8` | `#4A2A1C` |
| `band` / `on-band` | полоса-призыв | `#1B1510` / `#F1EADC` | `#E8683F` / `#15110D` |

Контраст проверен расчётом WCAG, все пары проходят AA. Минимумы: `ink-muted` на `sand` — 4,65 (светлая), текст `linen` на кнопке `terracotta` — 4,56 (светлая). Правило: текст цвета акцента всегда `terracotta-dark`, а `terracotta` используется только для фона и декоративных элементов (маркер-квадрат, звёзды). `themeColor` в `app/layout.tsx` обновляется на новые цвета `cream`.

Тени `--shadow-soft` и `--shadow-lifted` остаются, но применяются только к всплывающим элементам: меню аккаунта, мобильное меню, подсказки адреса, тосты. У карточек и блоков вместо тени рамка `border-ink/15`.

### Шрифты

Подключаются через `next/font/google`, у всех есть кириллица. Наличие в `font-data.json` нашей версии Next проверено.

| Переменная | Шрифт | Где |
|---|---|---|
| `--font-display` → `font-display` | Sofia Sans Condensed, 400–600 | заголовки капсом, цены, большие цифры, логотип |
| `--font-playfair` → `font-serif` | Playfair Display, курсив | одно акцентное слово в заголовке (`<em>`), названия книг, проявляющийся абзац |
| `--font-golos` → `font-sans` | Golos Text, 400–600 | основной текст, вместо Inter |
| `--font-mono` → `font-mono` | JetBrains Mono, 400–500 | навигация, кнопки, подписи, метки, даты |

Типографические правила:
- **Заголовки** `font-display uppercase`, межстрочный 0,9. Размеры через `clamp()`: h1 первого экрана — до 132 px, h1 страниц — до 104 px, h2 секций — до 88 px.
- **Акцентное слово** в заголовке: `<em>` → Playfair, курсив, без капса, обычный трекинг. Не больше одного слова или короткой фразы на заголовок.
- **Подписи** `font-mono text-xs uppercase tracking-[0.12em]`.

Для заголовков вводятся утилиты в `@layer components` в `globals.css`: `.display`, `.display em`, `.label`. Компонент `components/ui/Heading.tsx` не нужен.

### Геометрия и фактура

- `borderRadius.card` и `borderRadius.control` становятся `0px`, чтобы существующие `rounded-card` и `rounded-control` сразу стали квадратными. `rounded-full` остаётся у аватара, точек и звёзд.
- Тонкие рамки 1 px `border-ink/15`, сетки из «коробок» собираются через общие границы.
- Зерно бумаги: фиксированный слой `body::before` с SVG-шумом (`feTurbulence` в data-URI), `pointer-events: none`, прозрачность ~0,06, в тёмной теме ~0,05. Без canvas и анимации.

## Анимации и скролл

### Зависимости

| Пакет | Версия | Зачем |
|---|---|---|
| `gsap` | `^3.15.0` | ScrollTrigger, SplitText (бесплатные плагины в публичном пакете), ticker |
| `@gsap/react` | `^2.1.2` | `useGSAP` — создание в эффекте и автоматическая очистка |
| `lenis` | `^1.3.26` | плавный скролл. Peer-зависимости `vue` и `@nuxt/kit` необязательные и не ставятся |

`framer-motion@11` остаётся. Пакет `motion` не добавляется.

### Устройство

- **`lib/gsap.ts`** (`"use client"`): импортирует `gsap`, `ScrollTrigger`, `SplitText`, `useGSAP`, один раз вызывает `gsap.registerPlugin(...)` и реэкспортирует их. Все компоненты берут GSAP только отсюда.
- **`components/motion/SmoothScroll.tsx`** (`"use client"`), рендерится в `app/layout.tsx` внутри `<body>`:
  - `<ReactLenis root options={{ autoRaf: false, anchors: true, stopInertiaOnNavigate: true }} ref={lenisRef} />`;
  - в `useEffect`: `gsap.ticker.add(update)`, где `update = (time) => lenis.raf(time * 1000)`, затем `gsap.ticker.lagSmoothing(0)`; очистка через `gsap.ticker.remove`;
  - `useLenis(ScrollTrigger.update)` — синхронизация ScrollTrigger;
  - прокрутку при переходах делает сам Next: наверх для новой страницы, восстановление позиции при «назад». Lenis не вмешивается: `stopInertiaOnNavigate` гасит инерцию при клике по внутренней ссылке, поэтому она не перебивает прокрутку Next. Свой `scrollTo` при смене маршрута не вызываем;
  - при смене `usePathname()` — `ScrollTrigger.refresh()` в следующем кадре (`requestAnimationFrame`), чтобы пересчитать позиции после новой разметки.
- **`components/effects/`** — эффекты, каждый `"use client"`. У файлов, основанных на React Bits, шапка: `// Основано на React Bits <Имя> (https://reactbits.dev, MIT + Commons Clause), адаптировано`.

| Компонент | Основа | Поведение |
|---|---|---|
| `SplitHeading` | React Bits `SplitText` (GSAP) | `SplitText.create(el, { type: "lines", mask: "lines", autoSplit: true, onSplit })`, строки выезжают снизу с `stagger` 0,12 с при монтировании. Акцентный `<em>` сохраняется внутри строки. На элементе `aria-label` с полным текстом. |
| `RevealText` | React Bits `ScrollReveal` (GSAP) | Разбивка на слова, `gsap.fromTo(words, { opacity: .16 }, { opacity: 1, stagger, scrollTrigger: { trigger, start: "top 80%", end: "bottom 45%", scrub: true } })`. |
| `ScrollVelocity` | React Bits `ScrollVelocity` (Motion) | Импорт `motion/react` → `framer-motion`, стили на наших токенах, Tailwind 3. |
| `CountUp` | React Bits `CountUp` (Motion) | Импорт `framer-motion`, старт при попадании в зону видимости, формат `ru-RU`. |
| `Parallax` | своя | Обёртка над `next/image` с запасом по высоте 20–30%. `gsap.to(img, { yPercent: -k, ease: "none", scrollTrigger: { scrub: true } })`. |
| `FadeUp` | своя (GSAP) | Появление секций и карточек: `y: 32 → 0`, `opacity 0 → 1`, `once: true`, `stagger` для детей. |

- **Правила для всех эффектов:**
  - создание только внутри `useGSAP(() => …, { scope })`;
  - ScrollTrigger только на верхнеуровневых tween-ах и таймлайнах;
  - `markers` никогда.
- **`app/template.tsx`**: переход страниц только по `opacity`. Сдвиг `y` через `transform` убирается: он создаёт новый containing block и ломает `position: fixed` и `sticky` внутри страницы.

### Reduced motion и доступность

- Все GSAP-эффекты оборачиваются в `gsap.matchMedia()` с условием `(prefers-reduced-motion: no-preference)`. При `reduce` элементы остаются в конечном состоянии: текст виден, слова непрозрачны, параллакса нет.
- `ScrollVelocity` и `CountUp` используют `useReducedMotion()` из Framer Motion: строка статична, число сразу итоговое.
- Lenis при `reduce` сам отключает сглаживание (`respectReducedMotion` по умолчанию `true`).
- Разбиение текста не ломает чтение: исходный текст в `aria-label`, части `aria-hidden`.
- У всех интерактивных элементов видимый `focus-visible`: кольцо `terracotta` с отступом от фона.

### Производительность

- GSAP, ScrollTrigger и Lenis — на всех страницах (около 45 КБ gzip). SplitText и эффекты подгружаются только с использующими их клиентскими компонентами.
- Фото через `next/image` с корректными `sizes`. `priority` только у фото первого экрана.
- Без WebGL и canvas-фонов.

## Отзывы на главной

### API: `GET /api/reviews/latest`

Файл `app/api/reviews/latest/route.ts`, `runtime = "nodejs"`, `dynamic = "force-dynamic"`. Ответ с `Cache-Control: no-store`.

```sql
SELECT reviews.id, reviews.set_id, reviews.rating, reviews.text, reviews.created_at, users.name AS author_name
FROM reviews JOIN users ON users.id = reviews.user_id
WHERE reviews.rating >= 4
ORDER BY reviews.created_at DESC
LIMIT 10
```

Ответ: `{ reviews: LatestReview[] }`, где тип в `types/index.ts`:

```ts
export interface LatestReview {
  id: number;
  setId: string;
  rating: number;
  text: string;
  authorName: string;
  createdAt: number;
}
```

Запрос и маппинг строк выносятся в `lib/server/reviews.ts` (`getLatestReviews(limit)`). Ошибки БД не ловятся отдельно: Next отдаст 500, клиент спрячет блок.

### Клиент: `features/reviews/ReviewsRibbon.tsx`

- После монтирования `requestJson<{ reviews: LatestReview[] }>("/api/reviews/latest")`.
- Отзывы, чей `setId` не нашёлся через `getSetById`, отбрасываются.
- Если отзывов меньше 3, произошла ошибка или идёт загрузка, компонент возвращает `null`. Сдвиг макета ниже первого экрана допустим.
- **Разметка.** `Tag` «Читатели о наборах» и заголовок «Ощущения *вслух*». Горизонтальная лента `ul` с `overflow-x-auto`, `scroll-snap-x`, атрибутом `data-lenis-prevent-horizontal`. Справа над лентой кнопки «←» и «→» прокручивают на ширину карточки, на краях они `disabled`.
- **Карточка.** Около 400 × 360 px, чётные — на фото набора (`next/image`, затемнение, белый текст), нечётные — `bg-sand`. Внутри кавычка `“`, текст (обрезается до 220 символов по границе слова с `…`), имя, звёзды и атмосфера-ссылка на `/set/{id}` моношрифтом.
